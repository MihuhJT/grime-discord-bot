# Discord-бот для grime.fm

Бот воспроизводит отдельные треки grime.fm по ссылкам в голосовом канале Discord. Очередь хранится отдельно для каждого сервера и очищается при перезапуске бота.

## Что понадобится

- Python 3.10 или новее, FFmpeg в PATH и подключение к интернету.
- Приложение и бот в [Discord Developer Portal](https://discord.com/developers/applications).
- Сервер Discord, на который у тебя есть право добавить бота.

## Настройка Discord

1. Создай приложение в Developer Portal, открой **Bot** и создай или сбрось токен. Не публикуй токен и не отправляй его другим людям.
2. В **Installation** настрой установку на сервер. Для ссылки установки выбери scopes `bot` и `applications.commands`, а для бота — разрешения **View Channels**, **Connect** и **Speak**. Добавь бота на сервер. Проверь, что эти разрешения доступны ему и в нужном голосовом канале.
3. Для быстрой регистрации команд можно включить в Discord режим разработчика и скопировать ID сервера через его контекстное меню. Без ID команды регистрируются глобально и могут появиться с задержкой.

## Запуск

Установи FFmpeg. Например, на macOS через Homebrew: `brew install ffmpeg`; на Ubuntu/Debian: `sudo apt install ffmpeg`. На Windows установи FFmpeg и добавь папку `bin` в PATH. Проверь командой `ffmpeg -version`.

В терминале из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

На Windows используй `py -3 -m venv .venv`, затем `.venv\Scripts\activate` и `copy .env.example .env`. Открой `.env` в текстовом редакторе, укажи токен и, при желании, ID сервера. Запусти:

```bash
python bot.py
```

Терминал должен оставаться запущенным, пока нужен бот. Для круглосуточной работы потребуется постоянно работающий компьютер или сервер.

## Команды

Сначала зайди в голосовой канал, затем используй команды в текстовом канале сервера:

- `/play url: https://grime.fm/track/czar/monster-truck` — включить трек или добавить его в очередь.
- `/queue` — показать текущий трек и до 10 следующих.
- `/skip` — пропустить текущий трек.
- `/stop` — очистить очередь и отключить бота.

Управлять воспроизведением могут участники того же голосового канала. Бот принимает только ссылки на отдельные страницы треков grime.fm; поиск, альбомы и подборки пока не поддерживаются. Он использует адрес аудио, наблюдаемый в плеере сайта; если сайт изменит свой плеер или ограничения доступа, интеграцию придётся обновить. Соблюдай правила сайта и права на музыку.

Если команды не появились, проверь ссылку установки и `DISCORD_GUILD_ID`, перезапусти бота. Если звук не идёт, проверь FFmpeg, права бота на канал, доступ к grime.fm с компьютера, на котором он запущен, и сообщения в терминале.
